# Better Health

A responsive health-services web application focused on medical emergency awareness and preparedness.

## Features
- Emergency preparedness information
- First-aid guidance cards
- Emergency contact shortcuts
- Health service request form
- Responsive React interface
- Node.js/Express backend structure
- MongoDB model for storing service requests

## Tech Stack
React, JavaScript, CSS, Node.js, Express, MongoDB

## Project Structure
- `client/` — React frontend
- `server/` — Express API and MongoDB integration

## Run locally

### Frontend
```bash
cd client
npm install
npm run dev
```

### Backend
```bash
cd server
npm install
npm start
```

Create `server/.env` from `.env.example` before connecting MongoDB.
